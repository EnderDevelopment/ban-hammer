# BanHammer Mod

The BanHammer Mod is a Minecraft mod that adds a unique item to the game, the BanHammer. This item allows players to ban other players by right-clicking on them, executing the /ban command, and dropping the targeted player's inventory. The BanHammer has a distinctive appearance with a brown handle and a red head featuring white text that reads "BAN". This mod is designed for Minecraft Java Edition using the Fabric mod loader and is compatible with version 1.20.2.

## Install

1. Download the BanHammer Mod from the [GitHub repository](https://github.com/enderdevelopment/banhammer).
2. Place the downloaded JAR file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric mod loader installed.

## Use

1. Obtain the BanHammer item by crafting it or finding it in a loot chest.
2. Right-click on a player to ban them and drop their inventory.
3. The targeted player will be banned, and their inventory will be dropped on the ground.
